# 🍽️ Zomato Landing Page Clone

A **pixel-perfect, fully responsive** clone of the Zomato landing page, built with **pure HTML, CSS, and vanilla JavaScript** — no frameworks, no libraries (except Font Awesome for icons).

> **Live Demo:** Open `index.html` in your browser!

---

## 🎯 Features

### 🖌️ Design & UI
- **Premium glassmorphism** navbar with scroll-aware transparency
- **Full-viewport hero** with gradient overlay and animated background
- **Floating particle effects** in the hero section
- **3D tilt hover** on service cards with perspective transforms
- **Smooth scroll-reveal animations** using Intersection Observer
- **Animated number counters** with easing curves
- **Responsive design** — mobile, tablet, and desktop breakpoints
- **Modern typography** with Poppins + Playfair Display Google Fonts

### ⚡ Interactive Features
- **Typing placeholder animation** — search bar cycles through food suggestions
- **Parallax scrolling** on hero background
- **Hamburger mobile menu** with slide-in panel and backdrop overlay
- **Expandable accordion** for explore section
- **Click-to-search** popular tags and accordion items
- **Hover micro-interactions** throughout (links, cards, buttons)

### 📱 Sections
1. **Navbar** — Fixed, scroll-aware with glassmorphism
2. **Hero** — Zomato logo, search bar, popular tags, particles
3. **Service Cards** — Order Online, Dining Out, Nightlife & Clubs
4. **Collections** — Curated restaurant lists with image cards
5. **Popular Localities** — Nagpur-specific localities grid
6. **App Download** — Phone mockup with animated stats counter
7. **Explore Near Me** — Accordion with cuisines, types, chains, cities
8. **Footer** — Multi-column with social links and branding
